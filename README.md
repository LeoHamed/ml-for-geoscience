## About

This repository contains end-to-end Machine Learning projects focused on geoscience and energy applications, including:

- **Reservoir Property Prediction** (Porosity, Permeability, Saturation)
- **Well Log Facies Classification**
- **Geothermal Energy Analysis**
- **Carbon Capture and Storage (CCS) Screening**
- **Data Visualization for Subsurface Data**

## Projects
