# Project 01: Reservoir Porosity Prediction

## Objective
Predict core porosity from well log data using Machine Learning.

## Dataset
- Synthetic well log data (500 samples, 1500-3500m depth)
- Features: GR, RHOB, NPHI, DT
- Target: CORE_POROSITY

## Model
- Random Forest Regressor
- Train/Test split: 80/20

## Results
- R² Score: 0.872
- MAE: 0.0132
- RMSE: 0.0172

## Visualizations
- Well log multi-track plot
- Correlation matrix
- Predicted vs Actual scatter plot
- Feature importance analysis

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn
